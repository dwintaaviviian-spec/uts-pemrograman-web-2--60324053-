## Deskripsi Aplikasi

Aplikasi ini dibuat untuk memenuhi tugas UTS Pemrograman Web 2. Fungsinya untuk mengelola data kategori buku di perpustakaan dengan fitur sederhana seperti tambah, edit, tampil, dan hapus data.

Aplikasi ini menggunakan PHP native dan database MySQL.

## Alur Pengerjaan

Pada saat UTS, kami diminta membuat aplikasi berbasis web dengan studi kasus pengelolaan kategori buku. Pengerjaan dilakukan secara individu dalam waktu yang sudah ditentukan, dengan materi yang sudah dipelajari sebelumnya.

Fitur yang harus ada adalah CRUD (Create, Read, Update, Delete).

## Cara Menjalankan

1. Import database dari file `database_backup.sql` ke phpMyAdmin
2. Jalankan XAMPP atau Laragon (aktifkan Apache & MySQL)
3. Simpan folder project di dalam `htdocs`
4. Akses di browser:
   http://localhost/uts_60324053

## Struktur Folder

* config → koneksi database
* create.php → tambah data
* edit.php → edit data
* delete.php → hapus data
* index.php → tampilan utama
